# October 1, 2026 updates

Release: **v3.0.93**. This announcement covers customer-facing changes from
September 24 through October 1, 2026. Each item appears in New Features for
seven days after publication; this post remains available afterward.

## Global header search

**New · Experience**

Search players, matches, champions, items, cards, and talents from any page.
The header search shares the home search's suggestions, expands when opened,
and closes when you click outside it.

[Try search](https://paladinscat.com/search)

## Reviewed exploit exceptions

**New · Community**

Approved exploit exceptions now apply consistently to player profiles,
match badges, and account access. Moderators can review, grant, and revoke
these exceptions.

[Open the Exploiters directory](https://paladinscat.com/players/exploiters)

## Faster performance page

**Improved · Stats**

Performance charts and champion comparisons load together from a prepared
set of statistics, reducing separate loading steps.

[Open performance statistics](https://paladinscat.com/stats/performance)

## Older match loading

**Fixed · Analytics**

Older matches with complete stored scoreboards can open even when their
recovery status is incomplete.

[Find a match](https://paladinscat.com/matches)

## Specific request errors

**Fixed · Experience**

Failed requests identify the action and response details so you can tell
what failed and report the specific problem.

## Consistent scoreboard exports

**Fixed · Analytics**

Exported scoreboard images use the web view's font sizes, platform icons,
and current moderation labels.

[Find a match to export](https://paladinscat.com/matches)
