# New Features

> One place to discover the tools PaladinsCat adds for deeper Paladins analysis.

PaladinsCat turns match evidence into practical views for players, champions,
ranked performance, builds, and community tools. This page is maintained in
the public repository so the feature story can evolve without a frontend code
release.

## Champion analytics

[Compare champion performance](/champions), including role context, win rate,
pick rate, KDA, and the comparisons that help explain what is happening in the
current Realm.

## Player records

[Search player profiles](/players) to inspect match history, account-level
signals, progression, and the public record PaladinsCat has observed.

## Ranked tracking

[Follow ranked leaderboards](/players/leaderboard) for account and champion
level records, ELO context, and the current competitive picture.

## Performance and meta

[Compare performance benchmarks](/stats/performance) and explore [build and
meta trends](/builds) when you want more than a single match result.

## Discord companion

[Bring PaladinsCat into Discord](/operations/paladinscat-bot) for fast answers
without leaving the conversation.

## Keep exploring

Use the navigation and search to move from an overview into the underlying
player, champion, match, and stats pages. This document is the source for the
feature overview; edit it in GitHub to update the page after the normal content
cache refresh.
